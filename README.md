Незнакомцы из ада (Strangers from Hell)
Описание проекта
Данный проект представляет собой информационный сайт, посвящённый южнокорейской дораме «Незнакомцы из ада» (Strangers from Hell), вышедшей в 2019 году

Сайт знакомит посетителей с сюжетом дорамы, главными персонажами и основной информацией о сериале

Структура сайта
Сайт состоит из трёх страниц:

Главная (index.html) — описание дорамы, главные персонажи и информация о сериале.
Галерея (gallery.html) — фотографии и изображения персонажей дорамы.
Анкета (form.html) — форма для заполнения анкеты пользователем.
